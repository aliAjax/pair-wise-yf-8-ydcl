# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、统计总时长、筛选颜色偏移并生成试映前破损提醒。

「现场放映计时」区供放映员进厅后使用：

- 开始后高亮清单中正在放映的片段，按该段剩余秒数倒计时；
- 暂停会冻结已映秒数，再次开始从停下的秒数接着走；
- 临时跳过时记录该段已放映的秒数，随后自动进入下一段；
- 全部走完后汇总计划时长与实际放映时长，被跳过的片段仍按原顺序保留并显示备注；
- 放映状态（含已映秒数、跳过记录）保存在浏览器 localStorage，重开页面不丢；放映中关闭页面，重开时会按实际经过时间自动补走。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

逻辑自检：`node test-screening.js`（使用内置轻量 DOM 桩，无需安装依赖）。
