# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、统计总时长、筛选颜色偏移并生成试映前破损提醒。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 现场放映计时

清单下方的「现场放映计时」面板供放映员现场使用：

- **开始 / 暂停 / 继续**：开始后清单中正在放映的片段会高亮，并按该段剩余秒数倒计时；暂停后继续，从停下的秒数接着走。
- **跳过本段**：临时跳过会先记下这一段已经放映的秒数，再进入下一段；被跳过的片段保留原顺序和备注，标为「已跳过」。
- **汇总**：全部走完后显示计划时长、实际放映时长、差值和每段明细（含跳过段）。
- **断电恢复**：计时基于真实时间戳，放映进度、已放映秒数和跳过记录都存在 `localStorage`；重开页面会自动续算——关掉很久再回来，已自然走完的段会被自动追平，暂停中的段则停在原处。
- 「清空进度」可放弃本次记录重新开始。
